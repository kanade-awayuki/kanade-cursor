BOOTH ・ マウスカーソル

淡雪花奏マウスカーソルの入れ方ガイド

買ったカーソル（.ani 15種セット）を、Windows のマウスカーソルに設定する手順です。所要時間は5分くらい。

はじめに

このカーソルは .ani（アニメーションカーソル） 形式なので、使えるのは Windows だけです。

Windows 11 ○Windows 10 ○Mac ×

設定のしかた

  1. ZIP を展開して、置き場所を決める

    BOOTH からダウンロードした ZIP を右クリックして すべて展開。できたフォルダを、これから動かさない場所に置きます。

    おすすめ：「ドキュメント」の中に「カーソル」フォルダを作って入れる。設定したあとでフォルダを消したり移動したりすると、カーソルが元に戻ってしまいます。

  2. 「マウスのプロパティ」を開く

    Win + R を押して main.cpl と入力し、Enter。開いたら上の ポインター タブを選びます。

    または「設定」→ Bluetooth とデバイス → マウス →「マウスの追加設定」からでも開けます。

  3. 1つずつ「参照」でカーソルを当てはめる

    「カスタマイズ」の一覧で項目（たとえば 通常の選択）をクリック → 参照 → 展開したフォルダから同じ名前のファイルを選んで 開く。これを15種類くり返します。

    下のチェックリストで、終わったものに印をつけながら進めると迷いません。

  4. 名前をつけて保存する

    15種類ぜんぶ当てはめたら 名前を付けて保存 で「淡雪花奏」など好きな名前に。保存しておくと、あとで別のカーソルに変えても「デザイン」のリストから一発で戻せます。

  5. 「適用」→「OK」でできあがり

    すぐにカーソルが切り替わります。おつかれさまでした！

当てはめチェックリスト

Windows の一覧と同じ並び順です。小さい字はファイル側の名前。

0 / 15

Windows 11 の一覧の最後にある「場所の選択」「ユーザーの選択」はセットに入っていないので、そのままで大丈夫です。

こまったときは

いつのまにか元のカーソルに戻った
「設定」アプリでカーソルの色やスタイルを変えると外れます。マウスのプロパティの「デザイン」で、保存した名前を選び直せば戻ります。
配信画面に映したい
OBS などのキャプチャ設定で「カーソルをキャプチャ」をオンにすれば、このカーソルが映ります。配信での使用は OK のカーソルです。
